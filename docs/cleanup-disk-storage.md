# Disk storage cleanup — React Native / macOS

Typical recovery after a few months of React Native / Expo development: **10–20 GB**.

## Quick wins (run these first)

```bash
# CocoaPods cache — recovers 5–10 GB
pod cache clean --all

# Gradle cache (Android builds) — recovers 3–8 GB
rm -rf ~/.gradle/caches
```

## Node modules

```bash
# Interactive hunter — shows all node_modules folders ranked by size
npx npkill
```

## Expo / React Native build artifacts

```bash
# Xcode Derived Data (build cache) — safe to delete, rebuilt on next run
rm -rf ~/Library/Developer/Xcode/DerivedData

# Expo prebuild output — fully regenerated by `expo prebuild --clean`
rm -rf ios-app/ios ios-app/android

# Metro bundler cache
expo start --clear
# or
rm -rf ~/.metro
```

## iOS Simulators

```bash
# Remove unavailable/old simulator devices
xcrun simctl delete unavailable
```

Simulator runtimes (the big ones) are managed in **Xcode → Settings → Platforms** — delete runtimes you no longer test against.

## Visualise what's left

**DaisyDisk** (paid) or **OmniDiskSweeper** (free) give a visual breakdown of the full disk — useful for finding anything the commands above missed.
