# iOS App Store Submission

## Initial Prompt

Push the Popup iOS buyer app to the App Store as a public launch targeting organic discovery. Buyer-only, current feature set, Stripe live mode, backend at https://popup-live.fr.

## Context

The app is feature-complete for v1 (auth, onboarding, live discovery, live viewer with graceful Agora degradation on iOS 26, chat, bidding, Stripe + Apple Pay, orders, profile). It needs production configuration, real visual assets, and App Store Connect setup before it can be submitted.

## Out of Scope

- New features
- Seller flow
- Android
