# Feature 070 — Seller on iOS

## Initial prompt

> "I would like to introduce the seller feature on mobile. A seller needs to be able to build a shop by adding items and attach one picture to it. Then they can schedule lives and attach items that they plan to sell during these lives. Going live as broadcaster. Delivery and shipping with Mondial Relay and without (manual tracking URL). Seller onboarding should be a simplified waiting list. Real-time auction manageable from phone. Analytics is out of scope."

## Scope

A 5th "Vendre" tab is added for all users — non-sellers see an upsell + waitlist request, sellers see their full seller toolkit. The feature covers: seller access gate, inventory management, lives management, live broadcasting (Agora host mode), and deliveries.

## User Stories

| User Story | Status |
| :--------- | :----- |
| As a non-seller, when I tap Vendre, I see an upsell and can request seller access | planned |
| As a seller, when I tap Vendre, I land on my seller dashboard | planned |
| As a seller, I can view my product inventory | planned |
| As a seller, I can create a product with a name, price fields, and one photo | planned |
| As a seller, I can edit or delete a product | planned |
| As a seller, I can view my scheduled and past lives | planned |
| As a seller, I can schedule a new live with a date, description, and cover photo | planned |
| As a seller, I can attach and detach products from a live | planned |
| As a seller, I can go live from my phone and broadcast video | planned |
| As a seller, I can highlight products and run real-time auctions during a live | planned |
| As a seller, I can view my pending packages and manage shipping | planned |
| As a seller, I can generate a Mondial Relay label for orders with a relay point | planned |
| As a seller, I can enter a tracking number manually for non-Mondial Relay orders | planned |
| As a seller, I can request a payout for delivered orders | planned |
